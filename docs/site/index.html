01 · The Execution Gap

Privacy without preview is still blind risk

Institutional privacy vs. blind risk

Canton Network provides sub-transaction privacy — but institutional capital and autonomous agents still face execution failure risk before ledger settlement. Intent stays opaque until it commits.

The cloud leak trap

Standard EVM simulation tools leak transaction intent and treasury metadata to third-party RPC servers. Preview and policy must run where the keys live — locally.

The answer

An air-gapped, local-first simulation and gating firewall running natively in Daml and Rust: rehearse everything, commit only what's inside policy.

02 · Architecture & Dual-Engine Capability

One thesis, two engines

Canton / Daml — PreviewGate

  • Non-consuming Preview choices evaluate policy bounds
  • GatedPayment rules enforced before state commits
  • Owner grants are single-use; settlements carry audit trails

EVM Proxy — PreTxSim

  • Drop-in :8545 proxy, local revm state traces
  • Bridge & agent flows with zero telemetry outbound
  • --ci JSON reports for pipelines

AI agent guardrails

Local LLMs (Ollama) produce human-readable risk briefs before autonomous payment requests are signed — deterministic checks decide, the model only advises.

03 · Key Use Cases

Who runs this

Treasuries

Spending limits and multi-signature execution bounds natively in Daml templates.

AI agents

Sandboxed pre-flight checks — no drained funds, no unintended choice executions.

CI/CD gates

Automated transaction regression tests via --ci flags in deployment pipelines.

Node operators

Zero-knowledge, deterministic dry-run capability for network participants.
